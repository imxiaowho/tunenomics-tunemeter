# 默认脱敏与分享边界

采集器只读取已选择来源的已知用量目录，用白名单投影模型、计数、时间及本地核算所需标识；不从正文推算 token，不读取账号配置、凭据或云端账户。CLI 不调用网络或模型，不装 hook，不后台运行，不上传。

| 数据 | 本地处理 | 默认提交 ZIP |
| --- | --- | --- |
| 原始路径、文件名 | 用于打开选定用量源／写出目录 | 不保留原始值 |
| 会话标识 | 本地哈希别名用于核算 | 不包含会话别名或会话明细 |
| 事件标识、native 数值、逐事件／轮次明细 | 本地读取器核算／诊断；本地批次可能保留数值明细 | 不包含这些明细 |
| 正文、工具参数／结果 | 跳过未选字段，不进入用量记录 | 不包含 |
| 日期、小时、模型、Harness、汇总量与诊断 | 保留必要维度 | 保留；组合后仍可能有识别性 |
| 已选财务事实 | 单独整理声明／文档证据，不从 token 推断 | 可保留经过审阅的中性别名与必要事实；不附原账单 |
| 运行错误 | 固定类别／受限定位，不回显原生异常文本 | 拒绝时不生成正式 ZIP |

默认包为脱敏汇总，**不是绝对匿名**。本地目录不要整体分享。ZIP、模型与时间模式仍应由客户复核；manifest 证明文件一致性，不证明原始数据真实。

CLI 本身离线；将原件／本地批次／报告交给云端 Agent 阅读，内容可能已传给模型服务。事后脱敏无法撤回先前传输。本包没有通用附件自动脱敏，不能把任意 PDF／截图放入 ZIP 后宣称已处理。

直接验证覆盖精确哨兵排除、提交 JSON 结构、已知会话别名、有限标记差分和 manifest 逐文件校验。它们不能证明所有数据可重识别风险已消除。真实客户场景和未支持格式仍需单独验证。
