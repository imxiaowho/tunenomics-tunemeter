# 3.3.6 ZIP 文件名兼容修正

2026-11-03：针对部分解压器显示中文文件名乱码的反馈，默认提交包中的“脱敏说明.md”统一改名为 `redaction.md`。内容仍为 UTF-8 中文；README 和交付引用同步更新。当前默认汇总包内部文件名均为 ASCII，外层“元舵提交包.zip”名称保持。

检查此前导出的 3.3.5 样本，中文成员的 ZIP 本地头／中央目录均有 UTF-8 标志，原始文件名字节也匹配 UTF-8。因此不能将该样本的原因断言为“按 GBK 写入”；此次采用 ASCII 内部命名规避解压器编码识别差异。不是对所有解压器的认证，也不改变历史 ZIP。

计量、脱敏字段、缺口规则和 manifest 哈希算法不变。使用新版对已有批次执行 export 即可生成新包，不需要重扫原始日志；历史包保留。请先阅读 redaction.md，再复核提交。

3.3.5 的 19/19、40/40 合成回归是历史证据，不作为 3.3.6 的运行通过声明。此次只做源码语法、构建和实际导出包的文件名／UTF-8 正文／manifest 完整性检查，未新增或运行回归测试；未做所有 Windows 解压器 UI 复测。
